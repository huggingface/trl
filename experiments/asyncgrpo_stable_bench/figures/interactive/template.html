Six RL libraries on one B200 node

TRL, prime-rl, verl, OpenRLHF, SkyRL and miles on the same math and agentic tasks, each on its own built-in options, one 8×B200 node per run (4 GPUs for inference, 4 for training), one eval script for everyone.

Libraries

W2: agentic terminal tasks

TermGrade tasks as Harbor tasks with the terminus-2 agent, 600 s and 30 calls per episode, Qwen3.5-9B full fine-tune (and Qwen3.5-35B-A3B with LoRA, runs landing), 8 tasks × 8 episodes per step, 60 steps. At 9B only TRL and prime-rl ran it on built-in options; verl and miles runs show up here once collected.

Agentic (W2): Qwen3.5-35B-A3B on text-to-SQL

miles' text-to-SQL recipe (BIRD-based, multi-turn SQL tool calls, up to 5 tool turns and an answer turn) with LoRA r32 on Qwen3.5-35B-A3B. Each library runs its own recommended setup; only the task data, tool, reward and the greedy eval are shared. TRL and prime-rl on 8 B200s, SkyRL on 4.

W1: single-turn math

DAPO-Math-17k, 32 prompts × 8 samples per step, completions up to 16k tokens, 200 steps, Qwen3.5-2B and Qwen3.5-9B (hybrid gated-DeltaNet models). Eval: AIME24 and AIME25 avg@16, MATH-500 avg@1, 16k tokens, thinking off.

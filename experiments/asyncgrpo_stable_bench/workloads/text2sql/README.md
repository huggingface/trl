# Text-to-SQL (miles' River recipe) with TRL AsyncGRPO on Qwen3.5-35B-A3B

The 35B agentic benchmark uses miles' `examples/text_to_sql` recipe. Code: `workloads/text2sql/` (episode + reward port `t2sql_episode.py`, data `convert.py`, CPU reward test `test_reward.py`, vLLM probe/eval `probe_eval.py` + `eval.sbatch`, checkpoint evals `t2sql_evals.sh`), TRL training in `launch/trl/` (`t2sql_train.py` + `t2sql_train.sbatch` + `t2sql_watchdog.py`), miles' own run in `launch/miles/t2sql.sbatch`. Data and sources: `/fsx/amine_dirhoussi/stable-bench-src/text2sql/`. Times are `date -u`.
